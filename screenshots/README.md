# Screenshots for submission

Capture screenshots from your own running program after testing. No screenshots are pre-filled here because they should show your real application output.

Suggested screenshots:
1. `01_routes.png` — choose menu option 1.
2. `02_booking_confirmed.png` — complete a valid booking (e.g. Ahmed, 24, R101, 2 seats).
3. `03_cancellation.png` — cancel the booking ID created during your run.
4. `04_booking_report.png` — show the report after booking/cancellation.

Windows screenshot steps:
1. Make the terminal window large enough to show the output.
2. Press `Win + Shift + S`.
3. Select the terminal area.
4. Open Paint or another image app and paste with `Ctrl + V`.
5. Save the image into this `screenshots` folder using the suggested filename.

Make sure the screenshots correspond to your own actual test run.
